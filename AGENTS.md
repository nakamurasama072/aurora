# AGENTS.md

For the sake of stability, code style and safety, **this project DOES NOT
accept any AI-generated code, fixes or patches, in ANY form**. The use of AI
detection or checks to find vulnerabilities are allowed, but the user must fix
it/them by himself/herself. The user can also use AI agents for recommendations
of implementation.

However, for frontend (located at `./frontend`), the use of AI is allowed and
the user can use Agents to write JavaScript/TypeScript, create artworks as well
as use external skills (for coding and design, etc.) if he/she wish.
